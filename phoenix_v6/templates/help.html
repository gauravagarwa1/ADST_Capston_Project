HELP & RESOURCES

Everything you need to run Phoenix.

A short guide for the student, teacher and analytics workflows.

TEACHER WORKFLOW

Assignment → review → grade

  1. Create an assignment with subject, class, due date and points.
  2. Students see it automatically on their dashboard.
  3. Review submitted work in Evaluation inbox.
  4. Run the preliminary AI assessment.
  5. Publish the teacher grade; only the published grade becomes final.
STUDENT WORKFLOW

Discover → build → submit

  1. Open an assigned challenge.
  2. Build the project and attach files.
  3. Save a draft or submit for review.
  4. Read teacher feedback and final marks.
  5. Track skills, points and career guidance.
DATA CENTER

Multiple datasets, one workspace

Upload CSV/XLSX files from Analytics → Report & data. Each file is stored separately. Use Open dashboard beside a dataset to view its generated charts without replacing the live Phoenix database.

Tip: Keep the live database for application activity and use uploaded datasets for experiments, reports and external analysis.
TROUBLESHOOTING

If something looks empty

  • Refresh Analytics.
  • Confirm the server is running.
  • Check that the dataset contains rows and numeric/categorical columns.
  • Use Report & data to open the dataset dashboard.
